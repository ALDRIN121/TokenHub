# TokenHub 0.1.6

TokenHub now has a refreshed top navigation dashboard with coordinated light and dark themes, a stacked agent-usage chart and clearer sessions and filters.

## Dashboard improvements

- Persistent top navigation, a new chart-mark identity, responsive spacing and locally bundled agent icons.
- Prominent token totals, agent-colored percentage badges and compact mobile session cards.
- An agent picker with icons, keyboard navigation and type-to-find selection.
- Today, Yesterday, recent-day presets, single-date selection and custom inclusive date ranges that persist in bookmarks and browser navigation.
- Daily, weekly and calendar-month grouping, with the plotted date span and interval unit visible. Sparse-data guidance explains when few dates contain recorded usage.
- Chart details appear without shifting the surrounding page. Unknown or incomplete intervals retain visible gaps instead of inventing usage.
- A relative last-refresh time based on the last completed scan.
- Recorded model-name previews under each session's agent; expand a row for full model counters.
- Subtle hover, navigation and panel transitions that respect reduced-motion settings.

## Reliability

- Agent chart series reconcile with the selected period totals; changing grouping retains the same overall usage.
- Model-session drilldowns preserve full-session context and totals.
- Existing source approvals, exact-counter inspection, unknown-value handling, theme preferences and sync recovery remain available.

## Documentation and upgrade

Read the [dashboard guide](https://github.com/ALDRIN121/TokenHub/blob/v0.1.6/docs/dashboard-guide.md) for filters, chart grouping, sessions, sync, themes and keyboard controls. A copy is attached to this release as `dashboard-guide.md`.

```sh
python -m pip install --upgrade tokenhub
tokenhub stop
tokenhub start
```

Restart TokenHub and reload the dashboard after upgrading. Existing approved sources and local usage data are retained. Requires Python 3.12 or later.

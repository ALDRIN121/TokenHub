# TokenHub 0.1.7

TokenHub now installs and runs on Python 3.10 and newer. The published package previously required 3.12, so installations on 3.10 or 3.11 were refused before TokenHub could start.

## Compatibility

- `Requires-Python` is now `>=3.10`.
- New `tokenhub.compat` module supplies the pieces the standard library only added in 3.11:
  - `UTC` as an alias of `timezone.utc`, including on 3.12 where `datetime.UTC` exists;
  - a `StrEnum` fallback that preserves value-based comparisons, conversion and formatting;
  - an ISO-8601 parser that accepts a `Z` suffix and fractional seconds longer than six digits.
- Claude Code and Codex session parsing uses the compatibility parser, so existing session files import unchanged.
- CI verifies Python 3.10 and 3.12 on Linux, macOS and Windows.

## Upgrade

```sh
python -m pip install --upgrade tokenhub
tokenhub stop
tokenhub start
```

Restart TokenHub and reload the dashboard after upgrading. Existing approved sources and local usage data are retained. Requires Python 3.10 or later.

## Verification

Local validation passed 555 backend tests (2 skipped) on Python 3.10.21 and 3.12.7, including the integration checks, plus Ruff, mypy, the production dashboard build and a clean install of the built wheel in a Python 3.10 environment. The wheel metadata reports `Requires-Python: >=3.10`.

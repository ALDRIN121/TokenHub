# TokenHub 0.1.5

The dashboard now puts token usage first: a compact summary and all five agents are visible before operational details, and selecting an agent leads directly to its models and sessions.

## Dashboard improvements

- Compact usage summary, authentic local agent icons and consistent teal usage-share bars.
- One continuous overview and analysis workspace, with header navigation that scrolls to Models or Sessions.
- Selected agents remain highlighted across navigation, browser Back and reload. Table tabs retain independent search, sorting and pagination.
- Sticky analysis context, direct agent switching, inset filter arrows and responsive tables.
- A header light/dark switch with a saved preference and reduced-motion support.
- Sync progress and import issues in a header drawer; source setup and health in Sources. Coverage guidance stays available next to the total.

## Reliability

- Valid token usage can load even when collection status, discovery or quality metadata fails.
- Old rows and counters cannot appear as the newly selected date/agent while requests are pending or fail.
- Returning from a model's sessions to Models clears the drilldown filter while retaining model table context.
- Existing observed-counter normalization, source approval, unknown-value handling and precise chart data remain available.

## Documentation and upgrade

Read the [dashboard guide](https://github.com/ALDRIN121/TokenHub/blob/v0.1.5/docs/dashboard-guide.md) for navigation, sync, accuracy, themes and keyboard controls. A copy is attached to this release as `dashboard-guide.md`.

```sh
python -m pip install --upgrade tokenhub
tokenhub stop
tokenhub start
```

Restart TokenHub and reload the dashboard after upgrading. Existing approved sources and local usage data are retained. Requires Python 3.12 or later.

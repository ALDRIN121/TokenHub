# Agent icon sources

Downloaded October 6, 2026. Local copies keep the dashboard independent of third-party image requests.

- Codex: OpenAI’s official GitHub organization avatar (OpenAI Blossom), resolved via [organization metadata](https://api.github.com/orgs/openai). [Asset](https://avatars.githubusercontent.com/u/14957082?v=4). Represents OpenAI Codex consistently with the concept image.
- Claude Code: Claude’s published favicon from the [official Claude website](https://claude.com/). [Asset](https://assets.claude.com/95a868946ac8a31e5ff832e2899f294aa368b836.png?w=128&h=128).
- Hermes: [official Hermes Agent master icon](https://github.com/NousResearch/hermes-agent/blob/main/assets/icon-master.svg). This is also the repository’s documentation favicon. Preserves the published artwork rather than the generated purple H placeholder.
- Antigravity: full-color icon from [Google’s press assets](https://antigravity.google/press). [SVG](https://antigravity.google/assets/image/brand/antigravity-icon__full-color.svg).
- Copilot: [GitHub’s Copilot Octicon](https://github.com/primer/octicons/blob/main/icons/copilot-24.svg), rather than a GitHub Octocat. Its MIT notice is included in COPILOT-LICENSE.txt. Hermes’s repository notice is included in HERMES-LICENSE.txt.

Artwork proportions and colors are preserved. Uniform white icon plates keep the marks legible in both themes. All usage-share bars use the application teal, matching the generated design direction; agent brand colors do not recolor the bars.
